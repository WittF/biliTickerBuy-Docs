# 故障排除指南

本页面提供了使用B站抢票工具时可能遇到的常见问题的具体排除方法。

## 启动问题

### 程序无法启动

**现象**：双击程序后没有任何反应，或闪退

**可能的解决方法**：
1. 确保已关闭所有代理或VPN服务
2. 以管理员身份运行程序
3. 检查是否被杀毒软件拦截，尝试添加到白名单
4. 确保Windows Defender没有阻止程序运行
5. 尝试将程序放在纯英文路径下运行

### 控制台出现乱码

**现象**：控制台窗口显示乱码字符

**解决方法**：
1. 右键点击控制台窗口顶部 → 属性
2. 切换到"字体"选项卡，选择支持中文的字体
3. 确保系统区域设置为中文

## 网络问题

### 无法访问Web界面

**现象**：浏览器无法访问`http://127.0.0.1:7860`

**排除步骤**：
1. 确认控制台窗口是否仍在运行
2. 检查控制台是否显示了不同的端口号
3. 尝试使用`localhost:7860`替代`127.0.0.1:7860`
4. 检查防火墙是否阻止了程序的网络连接
5. 确保没有其他程序占用7860端口

### 登录失败

**现象**：扫码后无法成功登录或提示登录失败

**解决方法**：
1. 确保B站账号状态正常
2. 尝试在浏览器中手动登录B站，确认账号可用
3. 清除浏览器缓存后重试
4. 如果使用代理，请暂时关闭后再尝试
5. 尝试使用控制台显示的备用登录方法

## 配置问题

### 配置生成失败

**现象**：点击生成配置按钮后没有反应或报错

**排除步骤**：
1. 检查是否正确输入了票务URL
2. 确保已成功登录B站账号
3. 查看控制台是否有错误信息
4. 尝试重新启动程序后再次操作

### 配置无法导入

**现象**：导入配置文件时提示格式错误

**解决方法**：
1. 确保导入的是由本程序导出的配置文件
2. 检查文件是否被意外修改
3. 尝试使用文本方式复制配置内容再粘贴导入

## 抢票问题

### 定时抢票不启动

**现象**：到了设定时间但没有开始抢票

**排除步骤**：
1. 检查系统时间是否准确（建议使用网络时间同步）
2. 确认时间格式输入正确（YYYY-MM-DD HH:MM:SS）
3. 检查控制台输出是否有错误信息
4. 确保程序在设定时间前保持运行状态

### 验证码识别失败

**现象**：反复提示验证码识别失败

**解决方法**：
1. 切换到手动识别模式
2. 确保网络连接稳定
3. 检查是否启用了网络代理服务
4. 使用验证码测试功能确认验证码服务是否正常

### 提示"票已售罄"

**现象**：始终无法抢到票，显示"票已售罄"

**可能的原因及解决方法**：
1. 热门票确实已售罄，尝试使用蹲票模式等待回流票
2. 检查网络连接是否稳定，尝试使用更快的网络
3. 减小抢票间隔（在合理范围内）
4. 检查票务URL是否正确，确保指向正确的场次

## 系统资源问题

### 程序占用资源过高

**现象**：程序运行时CPU或内存占用过高

**解决方法**：
1. 关闭不必要的后台程序
2. 适当增加抢票间隔
3. 确保系统没有运行其他资源密集型应用
4. 重启程序尝试释放资源

### 程序崩溃

**现象**：程序突然关闭或不响应

**排除步骤**：
1. 检查系统事件日志寻找崩溃原因
2. 确保系统有足够的可用内存
3. 检查杀毒软件是否干扰了程序运行
4. 尝试重新下载最新版本的程序

## 其他问题

### 提示音不工作

**现象**：抢票成功但没有提示音

**解决方法**：
1. 确认系统音量是否已开启
2. 检查控制台是否有关于音频播放的错误提示
3. 确认"抢票提醒"选项已开启
4. 尝试重启程序

### 多账号冲突

**现象**：使用多个程序实例时出现冲突

**解决方法**：
1. 确保每个实例使用不同的端口（可通过命令行参数指定）
2. 将不同实例放在不同的文件夹中运行
3. 避免在同一浏览器中打开多个Web界面
