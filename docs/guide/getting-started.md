# 快速开始

本指南将帮助你快速上手B站抢票工具，了解基本的抢票流程和操作方法。

## 前置条件

在开始使用前，请确保你已经：

1. 完成了[安装](/guide/installation)步骤
2. 拥有一个B站账号
3. 在B站会员购中心完成了实名认证
4. 在B站会员购中心设置了配送地址

## 启动程序

1. 运行程序后，请注意控制台窗口的输出信息
2. 在浏览器中访问控制台显示的地址（默认为 `http://127.0.0.1:7860`）

::: warning 注意
- 请确保已关闭代理或科学上网工具
- 如果遇到浏览器启动失败，请参考[浏览器驱动问题解决方案](/guide/troubleshooting#浏览器驱动问题)
:::

## 配置抢票

### 1. 登录账号

首次使用时需要登录B站账号：

1. 在程序主界面输入抢票网址
2. 点击下方按钮，会弹出浏览器进行登录
3. 在浏览器中扫码登录B站账号

### 2. 生成配置

完成登录后：

1. 按照页面提示填写配置信息
2. 点击"生成配置"按钮
3. 保存或复制配置信息，用于后续抢票

### 3. 多账号配置

如果需要使用多个账号：

1. 为每个账号生成单独的配置文件
2. 使用不同的文件名保存配置
3. 在抢票时可以通过导入按钮快速切换账号

## 开始抢票

1. 在抢票配置界面导入之前保存的配置
2. 设置抢票时间（这是发送抢票请求的时间点）
3. 设置抢票间隔（推荐300ms）
4. 点击"开始抢票"按钮

::: tip 验证码处理
- 热门票务可能会触发验证码
- 建议在正式抢票前，使用验证码测试功能熟悉处理流程
- 推荐使用"本地自动识别"模式
:::
