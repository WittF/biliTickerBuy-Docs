# 快速开始

## 简介
biliTickerBuy 是一个用于 B 站抢票的自动化工具，支持会员购各类票务的自动抢购。

## 主要特性
- 支持多平台（Windows/macOS/Linux）
- 支持多架构（AMD64/ARM64）
- 自动登录验证
- 智能抢票策略
- 多账号支持
- 实时状态监控
- 自定义配置

## 快速上手
1. 下载安装
   - 根据您的系统选择对应的版本
   - 参考[基础配置](/guide/basic)页面进行安装

2. 配置参数
   - 设置必要的 cookie 和目标票务信息
   - 可选的高级配置请参考[高级配置](/guide/advanced)页面

3. 开始使用
   - 运行程序开始抢票
   - 查看运行状态和日志
