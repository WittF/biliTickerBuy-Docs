# 故障排除指南

本页面提供了使用B站抢票工具时可能遇到的常见问题的具体排除方法。

## 启动问题

### 程序无法启动

**现象**：双击程序后没有任何反应，或闪退

**可能的解决方法**：
1. 确保已关闭所有代理或VPN服务
2. 以管理员身份运行程序
3. 检查是否被杀毒软件拦截，尝试添加到白名单
4. 确保Windows Defender没有阻止程序运行
5. 尝试将程序放在纯英文路径下运行

### 控制台出现乱码

**现象**：控制台窗口显示乱码字符

**解决方法**：
1. 右键点击控制台窗口顶部 → 属性
2. 切换到"字体"选项卡，选择支持中文的字体
3. 确保系统区域设置为中文

## 网络问题

### 无法访问Web界面

**现象**：浏览器无法访问`http://127.0.0.1:7860`

**排除步骤**：
1. 确认控制台窗口是否仍在运行
2. 检查控制台是否显示了不同的端口号
3. 尝试使用`localhost:7860`替代`127.0.0.1:7860`
4. 检查防火墙是否阻止了程序的网络连接
5. 确保没有其他程序占用7860端口

### 登录失败

**现象**：扫码后无法成功登录或提示登录失败

**解决方法**：
1. 确保B站账号状态正常
2. 尝试在浏览器中手动登录B站，确认账号可用
3. 清除浏览器缓存后重试
4. 如果使用代理，请暂时关闭后再尝试
5. 尝试使用控制台显示的备用登录方法

## 浏览器驱动问题

**现象**：浏览器启动失败或无法正常登录

**解决方法**：
1. 使用[哔哩哔哩cookie获取工具](https://login.bilibili.bi/)获取cookie
2. 在工具中扫码登录B站账号
3. 通过转换功能生成并下载cookie.json
4. 在程序主页导入cookie.json文件

## 配置问题

### 配置生成失败

**现象**：点击生成配置按钮后没有反应或报错

**排除步骤**：
1. 检查是否正确输入了票务URL
2. 确保已成功登录B站账号
3. 查看控制台是否有错误信息
4. 尝试重新启动程序后再次操作

### 配置无法导入

**现象**：导入配置文件时提示格式错误

**解决方法**：
1. 确保配置文件格式正确（JSON格式）
2. 检查文件编码是否为UTF-8
3. 尝试重新生成配置文件
4. 确保文件内容完整，没有被意外修改

## 验证码问题

### 验证码识别失败

**现象**：自动识别验证码失败

**解决方法**：
1. 确保网络连接稳定
2. 尝试切换到手动识别模式

## 其他问题

如果以上方法都无法解决你的问题，请：

1. 查看控制台输出的详细错误信息
2. 在[GitHub Issues](https://github.com/mikumifa/biliTickerBuy/issues)中搜索类似问题
3. 如果问题仍然存在，可以提交新的Issue
